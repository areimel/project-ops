# Changelog

## 0.1.0 - 2026-11-17
- First release of the template: a home menu (sheet index) linking to eight demo apps: Notes, Tasks, Editor, Clipboard, Timer, System info, News and Player
- Settings with three themes (Blueprint, Graphite, Kraft), light, dark or system mode, and an accent colour override
- Saved data in JSON files, with export, import and reset in Settings
- Native menu, command palette and shortcut help generated from one command table
- Tray icon, notifications, close to tray, deep links and a single-instance lock
- Typed IPC between the page and the main process, with every argument checked
